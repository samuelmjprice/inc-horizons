# Brand QA Audit

Audit date: 1 June 2026

## Summary

The site is aligned with the HORIZONS brand direction: calm, warm, refined, and operational without becoming harsh or dashboard-heavy.

## Checks

| Brand Area | Status | Notes |
|---|---|---|
| Main logo | Good | Official logo asset is used and centered in hero/header contexts. |
| Typography | Good | Soleil and Gill Sans Nova are used. |
| Palette | Good | Warm ivory, blush, bronze, soft green/blue accents. |
| Cards | Good | Soft surfaces and restrained borders. |
| Tags | Good | Pill styling is consistent and calm. |
| Buttons | Good | Brand-toned, rounded, not default blue. |
| Mobile spacing | Good | Cards stack and controls are tappable. |
| Admin tools | Good | Separated from primary event flow. |
| Visual noise | Improved | Floating navigation is compact and low-noise. |

## Recommendations

- Do not add decorative gradients/orbs.
- Keep icons minimal and functional.
- Avoid adding more tags unless they improve decisions.
- Use real event imagery only when it helps people understand the place, object, or setup.
