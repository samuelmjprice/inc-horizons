# Mobile Navigation Redesign Report

Date: 3 June 2026

## Summary

The mobile navigation now behaves like a grouped event app rather than a long-page up/down control.

## Changes Made

- Primary nav is compressed to nine top-level groups.
- Floating bottom pill now shows Top, Sections, current group, and Next group.
- Sections button opens a compact bottom sheet.
- Bottom sheet contains Overview, Today, Call Sheet, Schedule, Locations, People, Programme, Assets, and Admin.
- Floating pill hides while the mobile menu, section drawer, or open update/capture forms are active.
- Section-end navigation now moves between major groups rather than every small sub-section.

## Mobile Intent

Users can now enter a group, use compact sub-section chips, and move to the next major area without scrolling through the whole site.

## Remaining Work

- Add optional icon-only controls if a final icon set is approved.
- Re-test against real iPhone Safari once the live build is deployed.
