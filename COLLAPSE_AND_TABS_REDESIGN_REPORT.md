# Collapse and Tabs Redesign Report

Date: 3 June 2026

## Summary

The site now follows a shorter-page pattern: summary first, details one tap deeper.

## Changes Made

- Daily focus panels no longer open automatically.
- Capture Suggestions and Capture Log forms are collapsed behind form accordions.
- Menus remain grouped by date and collapsed by default.
- Guests / Namecards remain collapsed by default with expand/collapse controls.
- Podcast, speakers, rehearsals, restaurants, location schedules, room drops, swag allocations, and lanyards continue to use closed details patterns.
- Signage artwork visuals are moved behind an "Open signage visual" detail control to reduce visible image walls.

## Controls

- Menus keep Expand all / Collapse all controls.
- Guests / Namecards keep Expand all / Collapse all controls.
- Daily Focus keeps Open today / Collapse all controls.
- Native details accordions now receive updated aria-expanded state.

## Remaining Work

- Add dedicated Expand all / Collapse all controls to more individual sections if Samuel wants every group to have bulk controls.
- Consider paginating very large staff, supplier, and document lists after final onsite feedback.
