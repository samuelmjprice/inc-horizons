# HORIZONS Site Compression Implementation Report

Date: 3 June 2026

## Summary

The website has been compressed from a long document-style page into a grouped, mobile-first event app structure. The underlying data has not been deleted or rewritten.

## Top-Level Groups Implemented

- Overview
- Today
- Call Sheet
- Schedule
- Locations
- People
- Programme
- Assets
- Admin

## What Changed

- Primary navigation now shows only the nine top-level groups.
- Existing detailed sections are assigned to groups and shown one group at a time.
- Overview now behaves as a short launchpad with quick tiles.
- Locations group starts with map/location cards before location schedules, restaurants, and menus.
- People group contains contacts, escalation, staff, guests/namecards, and suppliers.
- Programme group contains podcast, speakers, entertainment, playlists, rehearsals, content capture, capture suggestions, and capture log.
- Assets group contains menus, swag, room drops, HORIZONS House, signage, documents, and archive.
- Admin tools are grouped behind Admin rather than appearing as normal event sections.

## Data Preservation

No approved source data was deleted. Source documents, import reports, admin tools, and tracker records remain available.
